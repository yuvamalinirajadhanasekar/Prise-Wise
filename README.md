# Prise-Wise
PriceWise is a web-based product price comparison platform that helps users compare product prices, ratings, reviews, and available shopping options in one place. Built using HTML, CSS, JavaScript, Node.js, and Express.js, it integrates Google Shopping search results through the SerpApi service to simplify online shopping decisions.
